> de code.

## Le fait qui commande l'ordre des choses

L'enquête terrain contenait depuis le début une liste de recrutement : **16 éleveurs ont laissé
leur numéro et accepté d'être recontactés ; 8 ont répondu « oui, certainement » à une bêta
gratuite.** La Phase 0 en demande cinq.

Elle n'avait jamais été exploitée.
